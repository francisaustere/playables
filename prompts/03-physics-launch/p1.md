GAME: PHYSICS LAUNCH (skeleton template, primitives only). Aim, set power, launch a ball that flies under gravity and bounces, to break every target with limited shots. Portrait stage 720x1280, fit contain, fixed camera. Put in game_spec.json (next prompts add more):
{{GAME_SPEC:meta,input,launcher,projectile,rules,entities}}

FIELD
Floor at rules.floorY (surface rect, line top edge). Left/right stage edges are walls if rules.sideWalls, else the ball is out beyond outMargin. Top open. Launcher ring at the level's launcher {x,y}; the ball rests on it before each shot.

INPUT (input.launchMode, ignored while the ball flies)
Angle 0 = right, 90 = up, clamped to [minAngle, maxAngle]. Launch velocity = (cos a, -sin a) * power * maxLaunchSpeed. Power < minPower on release = cancel, shot not used.
- slingshot: press anywhere except UI buttons = anchor A; pull = A - pointer, length clamped to maxPull; angle from pull, power = |pull|/maxPull; release launches.
- tapImpulse: while held, angle = direction launcher -> pointer; power meter ping-pongs 0-1-0 at meterSpeed cycles/s from 0; release launches.
- Keyboard, both modes: aimUp/aimDown rotate at aimSpeed deg/s from startAngle; hold charge (Space): slingshot power rises linearly to 1 in chargeTime, tapImpulse uses the oscillating meter; release launches.
While charging show: aim line from the ball (length 60 + 140*power), a power bar next to the launcher, and if previewEnabled previewDots dots of p0 + v t + 0.5 g t^2 over previewTime (no collisions, fading).

PHYSICS (one ball, radius look.size/2)
v.y += gravity*dt; v *= (1 - airDrag*dt); move with substeps n = min(8, ceil(|v|*dt / (radius*0.5))) so it never tunnels. Circle vs AABB for obstacles, floor, walls: push out along the normal, reflect the normal velocity * restitution (the obstacle type's restitution; floor/walls use projectile.restitution), multiply tangential velocity by friction. Bounce sound if normal speed > 80.
Targets (kind target, circles at x,y): if impact speed >= minBreakSpeed the target breaks (points, burst, popup) and the ball keeps going unaffected; slower = bounce like a wall.
Shot ends when speed < restSpeed for restTime s, or flight > maxFlightTime, or out of bounds. Then reset the ball on the launcher.

Obstacles (kind obstacle) are static rects {type,x,y,w,h}, x,y top-left. Temporary test level (data comes next prompt): launcher (140,1080), wall x380 y900 w40 h300, targets (560,1120), (600,760).

Skins (ball, target, obstacle, launcher) read only look. Check slingshot, tapImpulse and keyboard all launch identically; no tunneling at full power.
