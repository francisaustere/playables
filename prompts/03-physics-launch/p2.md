LEVELS
levels.list is played in order. Each level: shots, launcher {x,y}, obstacles [{type,x,y,w,h}] (type = obstacle entity id), targets [{type,x,y}] (type = target entity id). An optional level gravity overrides projectile.gravity. Build the level from data on enter; never hard-code positions. Targets and obstacles come from pools sized by limits; log a debug warning if a target overlaps an obstacle.

PHASES (inside PLAY)
aiming -> flying -> back to aiming, or LEVEL_CLEAR, or RESULT.
- Each launch uses one shot.
- The moment the last target breaks (even mid-flight): score += remaining shots * rules.shotBonus, go to LEVEL_CLEAR.
- Shot ended with targets left: shots left -> reset ball to aiming; no shots left -> RESULT lose.
- LEVEL_CLEAR is a state like RESULT without sendScore: shows the bonus, confirm or "Next level" button -> next level. After the last level -> RESULT win.
- Pausing cancels any charge in progress (inputs released); flight resumes exactly.

TRAIL
While flying, drop a dot every projectile.trailInterval s (pool limits.trailDots), fading out; clear it at the next shot.

SCORE AND SAVE
Score = target points + shot bonuses over the whole run, kept across levels. On RESULT: sendScore(score), save best and progress {bestLevel}.

SOUNDS (audio.sfx)
charge every 0.25 of power while charging, action on launch, bounce, targetBreak, levelClear, lose when out of shots, win after the last level.

EDGE CASES
- Release exactly at minPower launches; below it cancels without using a shot.
- Pressing the pause button never starts a charge.
- maxFlightTime ends endless bouncer loops; ball stuck between obstacles is pushed out along the deepest contact first and the shot ends by rest.
