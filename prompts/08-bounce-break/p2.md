LEVELS
Grid geometry from levels.grid: width = columns*blockWidth + (columns-1)*gap, centered; cell (c, r) center x = left + c*(blockWidth+gap) + blockWidth/2, y = top + r*(blockHeight+gap) + blockHeight/2. Build each level from levels.list[i].rows (cut or pad rows to columns). When a level is cleared: wait rules.levelClearDelay, then a LEVEL_CLEAR screen (text.levelClear, score, "tap or press Space") that leads to the next level with a new serve, lives kept. After the last level: RESULT win with score += rules.lifeBonus * lives. A level with no destructible block counts as cleared (debug warning only).

DIFFICULTY
Ball speed = min(curve(difficulty.ballSpeed, levelTime) * level.speedScale * slowFactor, difficulty.maxBallSpeed). curve() = linear interpolation between {at, value} points, holding the last value. levelTime restarts each level. Substeps grow with speed automatically.

POWER-UPS
When a block is destroyed, drop chance = the block dropChance if set, else rules.powerupDropChance; type picked among powerup entities by weight. The capsule falls at fallSpeed, is caught when it overlaps the paddle, lost below the stage. Effects by effect field (one handler each, no per-id branches):
- widePaddle: paddle width * value (max player.maxWidth), tween 0.15 s, for duration s.
- multiBall: each ball in play spawns value copies at +/-20 degrees from its direction, within limits.balls.
- slowBall: slowFactor = value for duration s.
Catching the same timed effect again refreshes its timer, no stacking. All timed effects end when a life is lost or the level changes. Losing a life only when the last ball is lost.

SAVE
On RESULT: sendScore(score), save best and progress {highestLevel}.

ROBUSTNESS
Balls, blocks, capsules, particles and popups come from pools sized by limits; skip spawns when empty. Paddle collision only counts when the ball is above the paddle center line and moving down. If the last block breaks while another ball is falling, the level is cleared and no life is lost. Pause during serve or flight resumes exactly.

Check with debug.invincible (ball bounces on the bottom instead of being lost): play level 3 with 6 balls at 1400 u/s for 3 minutes: no tunneling, no frame drops, no errors.
