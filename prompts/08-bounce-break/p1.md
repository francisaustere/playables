GAME: BOUNCE AND BREAK (brick breaker). Stage 720x1280 fit contain, fixed camera. Put these sections in game_spec.json:
{{GAME_SPEC:meta,input,rules,player,entities}}

FIELD
Walls left, right and top (rules.fieldTop), no bottom wall, pre-rendered line strokes. Block grid: 8 columns, blocks 80x36, gap 6, top row y 220, centered. For now one level with rows "11111111","11111111","1P1111P1","11111111"; symbol -> block entity with that symbol, "." = empty.

PADDLE
Rect player.width x player.height at (x, player.y), clamped inside the walls. left/right keys move it at player.speed; moveTo (drag, and plain mouse move if input.mouseFollow) sets its center x to the pointer x. A drag is never a launch.

BALL
Serve: the ball rests on the paddle and follows it; launch sends it at rules.launchAngle degrees from vertical, random side. Speed 700 u/s for now, re-applied each step to the current direction.
Paddle bounce, only when moving down and overlapping: offset = clamp((ball.x - paddle.x)/(paddleWidth/2), -1, 1), angle = offset * rules.maxBounceAngle from vertical, direction = (sin, -cos), ball placed above the paddle.
Walls reflect vx (sides) or vy (top) and push the ball inside. After any bounce, if |dir.y| < rules.minVerticalRatio set it to that value keeping its sign and re-normalize.

COLLISIONS (no tunneling)
Move each ball in n = ceil(speed*dt / rules.substepMaxMove) substeps. Per substep test walls, paddle, then only blocks in the 3x3 cells around the ball. Circle vs AABB: reflect on the axis of least penetration (both axes if penetrations are within 2 u: corner), push out, stop testing blocks for that substep.

BLOCKS
Hit: hp -= 1, flash. hp 0: destroyed, score += points, particles. Defined hp 0 = indestructible, not needed to clear. No destructible block left = level cleared (for now RESULT win).

LIVES
A ball below y 1280+radius is lost (back to pool). No ball left: lose a life, new serve; 0 lives: RESULT lose. sendScore(score).

Systems in order each step: input, paddle, ball (substeps + collisions), blocks, lives, level. Skins: drawPaddle, drawBall, drawBlock reading only look. Check: 3 min of play, no tunneling, paddle OK with keys, mouse, touch.
