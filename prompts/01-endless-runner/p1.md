GAME: ENDLESS RUNNER (skeleton template, primitives only). Top-down, portrait stage 720x1280 fit contain. The player auto-runs on lanes; the world scrolls down; switch lanes and jump to dodge obstacle rows. Put these sections in game_spec.json (genre part; next prompts add more):
{{GAME_SPEC:meta,text,input,rules,player,entities}}

PLAYER
Lane center x = 360 + (i - (lanes-1)/2) * laneWidth, at y = player.y. left/right move one lane (clamped), x tweened ease-out over laneSwitchDuration; a new press re-targets from the current x. Jump (if jumpEnabled): airTime = jumpDuration, drawn scaled 1 + (jumpScale-1)*sin(pi*t/jumpDuration) with a ground shadow; while airborne entities with jumpable=true are ignored, others still hit; lane switch in air only if airControl; jump in air is buffered until landing. Hitbox = AABB of look size * hitboxScale centered on the current x.

WORLD
Systems in this order each fixed step: input, scroll, spawn, player, collision, scoring, cleanup, end.
scroll: speed (u/s, 600 for now, a curve comes next prompt) moves every world entity down by speed*dt; distance += speed*dt/unitsPerMeter.
spawn: each time the world scrolled rowGap units (720 for now) spawn a row at y=-100. A row is one pattern string, one symbol per lane, symbol -> entity with that symbol, "." = empty (patterns come next prompt; for now use X.., .X., ..X).
SAFE PATH RULE: track safeLanes of the previous row. Accept a pattern only if one of its passable lanes (no non-jumpable obstacle, and no obstacle at all if jumpEnabled is false) is within maxShift lanes of a previous safe lane, maxShift = clamp(floor((rowGap/speed - reactionTime)/laneSwitchDuration), 0, lanes-1). Up to 8 tries, else spawn an empty row. Every row must always be passable.
collision: player vs obstacles in its band. Hit = lose a life, destroy that obstacle, hit sound + flash + shake. Lives 0 -> RESULT lose.
scoring: score += speed*dt/unitsPerMeter * pointsPerMeter * multiplier (float, multiplier 1 for now); display and sendScore use floor(score).
cleanup: entities below y 1380 go back to their pool.
Background: dashed lane separators in palette line, scrolling with the world, pre-rendered once.

Skins: drawPlayer, drawObstacle reading only look. Obstacles come from pools sized by limits. Check: a 2-minute run with no errors, lanes and jump work with keys, swipes, mouse drag and tap.
