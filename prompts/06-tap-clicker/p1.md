GAME: TAP & CHOOSE (clicker skeleton, primitives only). Portrait stage 720x1280 fit contain. Tap the core to earn coins, buy upgrades, reach the coin goal before time runs out. Put these sections in game_spec.json (genre part; next prompt adds more):
{{GAME_SPEC:meta,input,rules,economy,entities}}

CORE
The entity of kind "core" is drawn at (x, y) with its look. Action tap: Space keydown (ignore auto-repeat), or tapCore = pointer-down inside the core circle (each finger counts). Cap all taps at rules.maxTapsPerSecond, extra taps silently ignored. On tap: bank += tapValue and totalEarned += tapValue, squash by tapSquash, rising "+N" popup at the pointer (keyboard: core center) with random x offset +/- popupSpread.

ECONOMY
bank (float, spendable) and totalEarned (float, never decreases).
tapValue = (economy.tapValue + sum of level * effect.tapAdd) * multiplier.
perSecond = sum of level * effect.perSecond, times multiplier.
multiplier = product of effect.multiply ^ level.
Each fixed step: bank and totalEarned += perSecond * dt. Display floor values.

UPGRADES
economy.upgrades is data: cost(level) = floor(baseCost * costGrowth ^ level). Buy (actions buy1..buy4: keys 1-4 or tapping the button): if bank >= cost and level < maxLevel then bank -= cost, level + 1; otherwise a short shake of the button. At maxLevel show "MAX" and disable. Upgrade bar: 2x2 buttons at the bottom of the stage (y 900-1180, 320x120 each, 16 gap), each with icon (its look), name, level, cost (pickup color if affordable, textMuted if not) and effect hint ("+2/s", "x2"). Show key labels 1-4 once the keyboard has been used. Adding an upgrade entry in the spec must add a button without code changes (bar shows the first 4).

END AND SCORE
Win when bank >= rules.targetCoins. If rules.timeLimit > 0, lose when time runs out; timeLimit 0 = no timer, no lose. Score = floor(totalEarned) + (win ? floor(timeLeft) * timeBonusPerSecond : 0), clamped to Number.MAX_SAFE_INTEGER; sendScore(score) on RESULT, best = same value.

Systems in this order: input, economy, goal, fx. Skins: drawCore, drawUpgradeIcon reading only look. Check: a full run with keyboard only, mouse only, touch only (multi-touch), no errors.
