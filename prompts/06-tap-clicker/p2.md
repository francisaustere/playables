CHOICE CARDS
A timer counts down from curve(difficulty.choiceInterval, runTime) (linear interpolation of {at, value}, hold last). At 0, open a card with a random entry of levels.choices, never the same as the previous one: prompt + 2 options (label, effects). Panel 640x420 centered at y 760, slides up in 0.2 s over the upgrade bar, with a shrinking bar for rules.choiceTimeout; timeout = no effect, close. The economy keeps running and core taps still count while the card is open.
Choosing: actions choose1/choose2 = keys 1/2 or Left/Right, or tapping an option button. While a card is open keys 1/2 choose instead of buying, and the upgrade bar is dimmed and disabled for every input. A pressed buy button is cancelled when a card opens.
After choosing: show a result line on the card for 0.8 s ("+1.2K coins", "Taps x5 for 15 s", "Lost 600"), then close and restart the timer.

EFFECTS (applied in order, from effects[])
- addCoinsRatio value: bank += bank * value (positive part also added to totalEarned).
- addIncomeSeconds value: bank += perSecond * value (if perSecond is 0 use tapValue * value / 2); also added to totalEarned.
- gamble chance, winRatio, loseRatio: with probability chance bank += bank * winRatio else bank += bank * loseRatio; bank never below 0; losses never reduce totalEarned.
- boost target (tap, passive or all), multiply, duration: timed multiplier; at most limits.boosts active, the oldest is replaced. tapValue and perSecond multiply by the active boosts of their target and "all".
- discount value, duration: upgrade costs x value while active (costs update live).
Unknown effect types are ignored with a debug warning. Trivia cards are just options with a reward and a penalty.

PASSIVE POPUPS
Every rules.passivePopupInterval s, if perSecond > 0, a small textMuted "+N" popup at the core edge with the income of that interval.

NUMBER FORMAT
Short format everywhere: 999, 1.2K, 34.5K, 1.2M... using text.suffixes, 1 decimal under 100 of a unit, none above.

SAVE
progress {bestTime (fastest win in s, 0 if none), wins}. All popups and particles pooled by limits; if the pool is empty skip the popup, the coins still count.
