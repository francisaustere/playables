GAME: GRID & MATCH (match-3 skeleton, primitives only). Portrait stage 720x1280 fit contain. Swap neighbouring tiles to line up 3+ of a type. Put in game_spec.json (genre part; more next prompt):
{{GAME_SPEC:meta,input,board,entities}}

BOARD
For now one level: 7 cols x 8 rows, 5 tile types (the first 5 entities of kind "tile"), 20 moves, minMatch 3, 20 points per tile. cellSize = min((maxWidth-(cols-1)*cellGap)/cols, (maxHeight-(rows-1)*cellGap)/rows), board centered at x 360, y board.centerY, row 0 on top. Cells drawn as surface rounded squares, pre-rendered. Tiles drawn at cellSize*tileScale*look.size (look.size is a ratio of the cell for board pieces). Grid in flat typed arrays (type, bonus, cover per cell, -1 = empty).
Generation: fill cell by cell, never picking a type that makes a run of minMatch with placed tiles; regenerate if no valid move exists.

INPUT (same result on every input)
Keyboard: arrows/WASD move a cursor (player-colored ring); Space/Enter selects the tile; with a tile selected, an arrow swaps it with that neighbour. Pointer: cellTap = tap on a cell (select; a second tap on a neighbour swaps; same tile deselects; other tile moves the selection); cellSwipeLeft/Right/Up/Down = swipe starting on a cell, swaps with that neighbour as soon as the swipe threshold is crossed. Mouse drag works like a swipe. Pointer presses also move the cursor. Presses off the board are ignored.

TURNS
Player turn (IDLE, input on) then system turn (input locked, select/swap presses dropped, cursor still moves):
SWAPPING (swapDuration) -> CHECK -> no match: REVERTING (swapDuration, no move spent) -> IDLE. Match: one move spent -> CLEARING (clearDuration) -> FALLING (fallCellDuration per cell) -> CASCADE_CHECK (cascadePause) -> CLEARING again if new matches, else SETTLE -> IDLE.
Match detection: scan rows and columns for runs >= minMatch of the same type; overlapping runs form one group. Each cleared tile scores 20 points.
Gravity: in each column tiles fall down to fill empty cells; new random tiles enter from above the board and fall in.
Moves reach 0 at SETTLE -> RESULT (lose). sendScore(floor(score)).

Skins: drawTile per tile type reading only look (shape + color tell types apart; shape alone must be enough). Systems in this order: input, turn, match, clear, gravity, goal, fx. Check a full game with keyboard only, touch only, mouse only.
