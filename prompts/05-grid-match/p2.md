LEVELS
A run plays levels in order; the score accumulates. Each level sets cols, rows (2-9), tileTypes (first N tile entities, clamped), moves, goal ("score": score earned in this level >= target; "covers": no cover left) and layout: rows strings of cols symbols, "." normal, "#" hole (no cell, not drawn), a cover entity symbol = covered cell ("c" 1 layer, "C" 2 layers); empty layout = all normal. Wrong layout size: missing cells = ".", debug warning. Recompute the board layout for each level.

COVERS (hidden / revealed cells)
A covered cell hides its tile (draw the cover look with one dot per layer) and locks it: no select, no swap, not matched, does not fall. A match orthogonally adjacent to it, or a bonus effect hitting it, removes one layer (at most once per clear step). At 0 layers the tile is revealed and becomes normal (it may match in the next cascade step).
Gravity with holes and covers: in each column, holes and covered cells split it into segments; tiles compact down inside their segment; empty cells at the top of a segment get new tiles falling in from just above it.

PATTERNS AND BONUSES (only if rules.bonusesEnabled)
For each match group pick the first entry of rules.patterns that fits: "line" of size N = one run of length >= N; "LT" = a horizontal and a vertical run sharing a cell, total >= size. Score = pattern.points + cells * pointsPerTile, times the cascade multiplier. If the pattern has a bonus, one cell of the group keeps a tile with that bonus (the swapped cell if in the group, else the middle cell).
Bonus effects when the bonus tile is cleared: lineClear clears its row (made from a horizontal run) or column (vertical); bomb clears cells within radius (3x3); colorBomb has no type, swapping it with any tile is always valid and clears every tile of that type (colorBomb + colorBomb clears the board); hit by an effect it clears a random present type. Effects chain in the same clear step, each cell cleared once, and damage adjacent covers.

CASCADES
Depth d = 0 for the swap's matches, +1 per following clear step. multiplier = min(1 + d*cascadeStep, maxCascadeMultiplier).

SETTLE
1. Goal met -> add unused moves * movePoints, wait board.levelClearDelay, LEVEL_CLEAR screen (text.levelClear, Next button), then next level; after the last level RESULT win. Goal checked before moves.
2. Moves 0 -> RESULT lose.
3. Deadlock: test every swappable pair (right and down neighbours); none valid -> show text.shuffle 1 s, shuffle types of unlocked non-bonus tiles until no immediate match and a move exists (max shuffleTries, then regenerate those cells).
HINT: after rules.hintDelay s idle in IDLE, the two tiles of one valid move pulse until the next input.

SAVE: progress {highestLevel}. Pools sized by limits; skip particles when the pool is empty.
Check: play the 4 levels with debug.invincible (moves never decrease); holes, covers, bonuses and shuffle all work.
