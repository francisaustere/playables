MUSIC (Web Audio only, no files)
Extend the audio module with play(name, when) where when is an optional AudioContext time (default now).
Backing: each chart.backing track is a step string looping over the whole song from step 0; it plays its sfx on "x". Every frame, schedule the backing hits with time < songTime + rules.scheduleLookahead that are not scheduled yet, at the exact context time anchor + audioOffset + hitTime. With clock source B nothing is scheduled.
Hit sound: on Perfect or Good in lane i, play chart.laneSfx[i] immediately: the lane tones make the melody. Miss plays the miss sound.

HEALTH
Starts at rules.healthStart, clamped 0..1. Perfect += healthPerfect, Good += healthGood, Miss += healthMiss * curve(difficulty.missDamageScale, songTime), with curve() = linear interpolation between {at, value} points holding the last value. Ghost tap += ghostTapHealth. Health 0 -> RESULT lose. Note speed uses difficulty.travelTime.

PAUSE AND AUDIO STATE
- Pause (button, Esc/P or SDK onPause): song clock frozen, context suspended.
- Leaving PAUSED: songTime = max(0, songTime - rules.resumeRewind), re-anchor, reset the backing scheduler to the new time; already judged notes stay judged, notes after the new time come down again.
- YouTube audio toggled mid-song: master gain only, no clock change.
- Context not running (blocked, interrupted): switch to source B with re-anchoring, back to A when running. If Web Audio cannot start at all, the game is fully playable silent.

SAVE
On RESULT: sendScore(score), save best and progress {bestAccuracy, bestCombo}; accuracy = (perfect + 0.5*good)/notes judged.

ROBUSTNESS
Notes and popups from pools sized by limits; the note list is built once per song, no allocation during play. A 100 ms frame hitch must not cause false misses (judging uses song time and event timestamps). In a pattern, shorter lane strings are padded with ".".

Check: play the whole song muted and unmuted, pause mid-song and resume (2 s rewind, still in sync), toggle audio mid-song: no drift, no errors.
