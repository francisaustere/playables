GAME: MUSIC TAP (rhythm). Stage 720x1280 fit contain. Notes fall in 4 lanes; hit each lane when its note crosses the hit line. Put these sections in game_spec.json:
{{GAME_SPEC:meta,input,rules,player,entities,chart}}

LANES
Lane i center x = 360 + (i - (lanes-1)/2) * laneWidth; columns in surface with line separators, pre-rendered. Receptors (receptorLook) at player.hitY.

CHART
stepTime = 60/bpm/stepsPerBeat. Pattern = one string per lane, one char per step ("x" note, "." rest). At song start expand chart.sequence once into a sorted note list {lane, time = rules.leadIn + globalStep*stepTime}. songEnd = end of the last step + rules.endPadding.

SONG CLOCK (critical, no timers)
Source A: songTime = audioContext.currentTime - anchor - rules.audioOffset while the AudioContext is running (YouTube mute = gain 0, clock still runs). Source B: game time from the fixed step when the context is missing or not running. On any source switch re-anchor so songTime never jumps. Render with the frame's song time.
Note y = hitY - (note.time - songTime)/travelTime*(hitY - spawnY), with travelTime 1.4 s for now.

INPUT
lane0..lane3 actions: keys from bindings; laneZoneN = pointerdown inside lane N's column with y >= input.laneZoneTop (stage units), fires at once, each pointer independent (chords). Only presses count, ignore key repeat. Each press keeps its time: pressSongTime = songTime - (performance.now() - event.timeStamp)/1000.

JUDGE
Press in lane L: earliest unjudged note of lane L with |note.time - pressSongTime| <= goodWindow. None = ghost tap (no effect). Found: Perfect if the difference <= perfectWindow, else Good. Miss: unjudged note with songTime > note.time + goodWindow.
Perfect: +perfectPoints*multiplier, combo+1. Good: +goodPoints*multiplier, combo+1. Miss: combo = 0. Multiplier = multiplier of the last multiplierSteps entry with combo <= current combo. Count perfect/good/miss, max combo.
End: songTime >= songEnd -> RESULT win, sendScore(score).

Systems in order each step: clock, input, judge, scoring, notes (pooled; released when judged, or faded 0.3 s after a miss), end. Skins read only look. Check: notes cross the hit line on their step; lanes work with keys, mouse, multi-touch.
