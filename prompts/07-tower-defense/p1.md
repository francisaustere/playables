GAME: TOWER DEFENSE (skeleton, primitives only). Portrait stage 720x1280 fit contain. Enemies walk a path to the base; build towers on grid cells beside it. Put in game_spec.json (genre part; more next prompt):
{{GAME_SPEC:meta,board,entities}}

BOARD AND PATH
Grid cols x rows of cellSize, top at board.originY, centered horizontally; cell (c,r) center = origin + (c+0.5, r+0.5)*cellSize. For now use this path of nodes in cell coordinates: [[4,-1],[4,1],[1,1],[1,4],[7,4],[7,7],[1,7],[1,10],[4,10],[4,12]] (nodes may be off-board for entry/exit; segments horizontal or vertical). Enemies follow the polyline through node centers: store distance d, precompute segment lengths, position(d). Path cells are unbuildable, drawn surface with line borders; buildable cells faint line squares; pre-render grid and path once. Base (kind base) at the last in-board path cell, 20 HP for now. 120 coins at start.

PLACEMENT (same result on every input)
Cursor cell (player outline): arrows/WASD move it; cellTap (tap/click a cell) moves it there. Selected tower type defaults to the first tower. tower1/tower2 (keys 1/2 or the tower buttons of the bottom bar, from board.barTop to the bottom) select that type AND build it on the cursor cell if buildable and affordable. place (Enter, or tapping the cursor cell again) builds the selected type. Buildable = in board, not path, no tower. Build: coins -= cost. Not possible: cursor shake.

TOWERS AND PROJECTILES
Each step cooldown -= dt; when <= 0 and an enemy is in range: fire, cooldown += 1/fireRate (search targets only when ready). targeting "first" = largest d in range, "closest", "strongest" = highest hp. Projectiles home on the target at projectileSpeed; hit when distance <= speed*dt + enemy radius. Target dead: fly to its last position and resolve there. splashRadius 0 = damage the target only; > 0 = damage every enemy within splashRadius of the impact.

ENEMIES
Spawn at path start, move speed*dt along the path. HP bar above once damaged. Death: coins += reward, score += points. Reaching the end: baseHp -= damage, recycle. For now one wave of 10 basic enemies every 1 s, repeating 5 s after the previous one ends. Base HP 0 -> RESULT lose; sendScore(floor(score)).

Systems in this order: input, wave, enemy, tower, projectile, economy, end, fx. Enemies, projectiles, towers from pools. Skins (drawTower, drawEnemy, drawProjectile, drawBase) read only look. Check with keyboard only, mouse only, touch only.
