EVENT FORMAT
Event: id, who (character id: avatar look + name on the card), text, left/right choices, optional if, minTurn, once, weight (default 1). Choice: label, optional effects {statId: delta}, setFlags [], clearFlags [], next (event id forced as the next card), ending (ending id: ends the run after effects). Condition if: flags (all set), notFlags (none set), stats {statId: {min, max}} inclusive.

DECK
The deck is events plus every storylines[].events (storylines come in a later prompt; their events default to weight rules.storylineWeight). Next card:
1. the queued next event if it exists and its if passes, else drop the queue;
2. otherwise weighted random among eligible events: if passes, minTurn <= turn, not (once and already used), weight > 0, not among the last rules.noRepeatWindow cards;
3. none eligible: rules.fallbackEventId (weight 0 = fallback only); if missing, the first event.
Flags: a set of strings for the run (max limits.flags), reset each run, not saved. History of the last limits.history card ids.

ORDER ON EACH CHOICE
choice, effects, flags (setFlags then clearFlags), turn += 1, ending check (explicit choice ending first, then fatal stat, then target turns), deck pick if no ending.

DIFFICULTY
Effect scale = curve(difficulty.effectScale, turn): linear interpolation between {at, value} points, holding the last value. Scaled delta = round(delta * scale). The preview uses scaled deltas.

ROBUSTNESS
A missing character id shows a neutral ring avatar and no name. A next id that does not exist or fails its if is ignored (debug warning only). Two stats at extremes on the same choice: the first in stats order wins. Restarting a run resets stats to start, flags, history, used once-events and turn.

Check: play 3 runs; never the same card twice within noRepeatWindow, the mill chain starts after "Start building", the deck never gets stuck, no errors.
