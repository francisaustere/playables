GAME: NARRATIVE SIMULATION. Stage 720x1280 fit contain, UI only. You lead a settlement: each day a card brings a request with two choices that move four stats. Put these sections in game_spec.json:
{{GAME_SPEC:meta,input,rules,card,stats}}

LAYOUT
Stat icons (look) with vertical bars in a row at y 200 under the HUD. Card (card.look, card.width x card.height) centered at x 360, y card.y: avatar shape at the top, character name, event text wrapped once per card (max card.textMaxLines; if longer, step the font down 4 u, min 24). Two choice buttons at y 1130 (300x100 each) with the choice labels.

CHOICE (same on every input)
lean = none/left/right. chooseLeft/chooseRight: if rules.twoStepChoice and not already leaning that side, only lean; otherwise choose that side. confirm (Enter/Space or tap on the card) chooses the leaned side. Leaning moves the card 40 u to that side, rotates it card.tilt/2, highlights the label and button, and shows the preview.
cardDrag: card x = 360 + dx, rotation = card.tilt * clamp(dx/swipeThreshold, -1, 1); |dx| > 20 shows that side's lean; release with |dx| >= swipeThreshold chooses, else springs back in 0.15 s. Ignore input during card transitions (rules.transitionDuration).
PREVIEW by rules.previewMode: "dots" = a dot above each stat the leaned choice changes, small if |delta| < bigChangeThreshold else big, never the direction; "full" = + or - signs; "none" = nothing.

EFFECTS
On a choice: card flies off to that side, then for each effects[statId] = d: value = clamp(value + round(d * scale), min, max) with scale 1 for now; bars tween over rules.statTweenDuration. Then turn += 1. Fatal check: first stat in order with value <= min ends the run with its endingAtMin; else first with fatalAtMax and value >= max ends with its endingAtMax. If turn >= rules.targetTurns, the run ends with rules.winEndingId. For now show the ending id on RESULT.
Until the next prompt, repeat this test event: {"who":"farmer","text":"The harvest came early. Sell some?","left":{"label":"Keep it","effects":{"food":10,"coins":-5}},"right":{"label":"Sell it","effects":{"food":-10,"coins":15}}}.

SCORE
Score = turns survived (the ending choice included). On RESULT: sendScore(turn).

Systems on each choice, in order: choice, effects, turn, ending, next card. Per frame only drag, springs, tweens and transitions. Skins: drawCard, drawAvatar, drawStatIcon reading only look. Check: a run with keyboard only, taps only, drags only.
